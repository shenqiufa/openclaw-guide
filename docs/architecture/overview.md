## 📚 7 個核心文檔（AI 人格）

### 文檔定義

| 文檔 | 核心問題 | 內容類型 | 加載順序 |
|------|---------|---------|---------|
| **SOUL.md** | 「你是誰？」 | 價值觀、邊界、個性、原則 | 1 |
| **USER.md** | 「你在幫助誰？」 | 用戶姓名、時區、背景、偏好 | 2 |
| **IDENTITY.md** | 「你的個性是什麼？」 | 名字、emoji、風格、頭像 | 3 |
| **AGENTS.md** | 「你如何做？」 | 行為規則、工作流程、方法論 | 4 |
| **MEMORY.md** | 「你記住了什麼？」 | 用戶偏好、項目背景、關鍵教訓 | 5 |
| **TOOLS.md** | 「你用什麼工具？」 | 攝像頭、SSH、TTS、飛書等配置 | 按需 |
| **HEARTBEAT.md** | 「你主動做什麼？」 | 心跳檢查清單、定時任務說明 | 心跳時 |

### 文檔關係

```
SOUL.md（核心身份）
    ↓
IDENTITY.md（個性設定）
    ↓
USER.md（服務對象）
    ↓
AGENTS.md（行為方式）
    ↓
┌───────────────┐
│ TOOLS.md      │ ← 工具配置
│ MEMORY.md     │ ← 記憶經驗
│ HEARTBEAT.md  │ ← 主動行為
└───────────────┘
```

### 內容流動

```
價值觀 (SOUL.md)
    ↓ 指導
行為規範 (AGENTS.md)
    ↓ 使用
工具配置 (TOOLS.md)
    ↓ 記錄
經驗教訓 (MEMORY.md)
    ↓ 反饋
持續進化 (SOUL.md)
```


## 🧠 記憶系統（四層架構）

### 記憶分層

```
┌─────────────────────────────────────────────────────────┐
│                    四層記憶架構                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  HOT 層（.learnings/）                                   │
│  ├── LEARNINGS.md - 學習記錄（糾正、最佳實踐）          │
│  ├── ERRORS.md - 錯誤記錄（命令失敗、異常）             │
│  └── FEATURE_REQUESTS.md - 功能請求                     │
│  特點：當前活躍記憶（7 天內），快速訪問，頻繁更新        │
│                                                         │
│  WARM 層（memory/warm/）                                 │
│  ├── corrections.md - 糾正記錄                          │
│  └── best-practices.md - 最佳實踐                       │
│  特點：近期經驗（30 天內），常用經驗，定期回顧          │
│                                                         │
│  COLD 層（MEMORY.md）                                    │
│  ├── 用戶偏好                                           │
│  ├── 重要項目背景                                       │
│  ├── 核心工作原則                                       │
│  └── 關鍵教訓                                           │
│  特點：長期記憶（永久保存），精選記憶，手動管理          │
│                                                         │
│  ARCHIVE 層（.archive/）                                 │
│  └── 按月歸檔的歷史記錄                                 │
│  特點：已歸檔歷史，按需檢索                             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 記憶流動

```
實時捕獲
    ↓
HOT 層（.learnings/）
    ↓
記憶復述（每天 08:30）
    ↓
WARM 層（memory/warm/）
    ↓
記憶巩固（每週一 05:00）
    ↓
COLD 層（MEMORY.md）
    ↓
ARCHIVE 層（.archive/，按需歸檔）
```

### 記憶閉環

```
1. 實時捕獲（auto-memory-hook.sh）
    ↓
2. HOT 層（.learnings/）
    ↓
3. 記憶復述（每天 08:30）
    ↓
4. 記憶巩固（每週一 05:00）
    ↓
5. COLD 層（MEMORY.md）
    ↓
6. 優化行為（閉環完成）
```

## 🔄 數據流圖

### 日常會話流程

```
用戶輸入
    ↓
加載 7 個文檔
    ↓
AGENTS.md（行為規範）
    ↓
執行任務
    ↓
┌───────────────┐
│ 成功 → LEARNINGS.md（記錄經驗）│
│ 失敗 → ERRORS.md（記錄錯誤）  │
└───────────────┘
    ↓
心跳檢查（每 30 分鐘）
    ↓
記憶復述（每天 08:30）
    ↓
記憶巩固（每週一 05:00）
    ↓
MEMORY.md（長期記憶）
    ↓
優化行為（閉環完成）
```

### 自動記錄流程

```
事件觸發（Bug 修復/配置變更/會話結束）
    ↓
auto-memory-hook.sh
    ↓
生成記憶記錄
    ↓
写入 .learnings/LEARNINGS.md
    ↓
更新指標（update-learning-metrics.sh）
    ↓
心跳檢查時處理
```

## 🦞 核心原則

### 三不原則
- 不加沒被要求的東西
- 不做過度優化
- 不預防概率<1% 的情況

### 三法則
- 代碼抽象：第 3 次才提取函數
- 文檔重複：第 3 次才抽象成規範
- 記憶記錄：第 3 次才轉移到 COLD 層

### 安全紅線
- 禁止對外傳輸安全信息（密碼、token、API key）
- 禁止任何跟金錢相關的操作
- 破壞性命令先詢問
