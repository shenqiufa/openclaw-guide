# 7 個核心文檔架構

> 7 個文檔構成一個完整的 AI Agent 人格

**版本**: v4.8.2  
**創建時間**: 2026-04-05  
**最後更新**: 2026-04-08

---

## 📚 文檔定義

| 文檔 | 官方定義 | 核心問題 | 內容類型 |
|------|---------|---------|---------|
| **SOUL.md** | AI 的**身份定義** | 「你是誰？」 | 價值觀、邊界、個性、原則 |
| **USER.md** | **用戶信息** | 「你在幫助誰？」 | 用戶姓名、時區、背景、偏好 |
| **IDENTITY.md** | AI 的**個人設定** | 「你的個性是什麼？」 | 名字、emoji、風格、頭像 |
| **AGENTS.md** | **行為規範 + 工作流程** | 「你如何做？」 | 行為規則、工作流程、方法論 |
| **TOOLS.md** | **本地配置** | 「你用什麼工具？」 | 攝像頭、SSH、TTS、飛書等配置 |
| **MEMORY.md** | **長期記憶** | 「你記住了什麼？」 | 用戶偏好、項目背景、關鍵教訓 |
| **HEARTBEAT.md** | **心跳配置** | 「你主動做什麼？」 | 心跳檢查清單、定時任務說明 |

---

## 🔗 文檔關聯關係

### 加載順序（每次會話）

```
1. SOUL.md      ← 首先加載（身份定義）
2. USER.md      ← 第二個加載（服務對象）
3. IDENTITY.md  ← 第三個加載（個人設定）
4. AGENTS.md    ← 第四個加載（行為規範）
5. MEMORY.md    ← 第五個加載（僅 main session）
6. TOOLS.md     ← 按需查閱（工具配置）
7. HEARTBEAT.md ← 心跳時加載（主動行為）
```

### 內容流動關係

```
SOUL.md（價值觀）
    ↓
    指導
    ↓
AGENTS.md（行為規範）
    ↓
    使用
    ↓
TOOLS.md（工具配置）
    ↓
    記錄
    ↓
MEMORY.md（經驗教訓）
    ↓
    反饋
    ↓
SOUL.md（持續進化）
```

**循環**：價值觀 → 行為 → 工具 → 記憶 → 進化 → 價值觀

## 📊 文檔內容邊界

| **工作流程** | AGENTS.md | SOUL.md、HEARTBEAT.md |
