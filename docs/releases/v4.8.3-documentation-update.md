## 📊 更新概覽

v4.8.3 主要優化了定時任務腳本，將 5 個獨立腳本合併為 2 個，減少 60% 的維護成本。

### 新增腳本

|------|------|--------|
| `weekly-summary.sh` | 每週總結 | `memory-search.sh` + `emotion-detect.sh` + `self-reflect.sh` |
| `content-review.sh` | 內容審查 | `weekly-public-summary.sh` + `generate-guide-update-suggestion.sh` |
