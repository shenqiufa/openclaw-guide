# 成長計劃 (Growth Plan)

> 讓 AI Agent 成為高效、可靠、安全的人類智能夥伴

**版本**: v4.8.3  
**最後更新**: 2026-04-09  
**狀態**: ✅ 持續進化中

---

## 🎯 使命

讓 AI Agent 高效、可靠、安全地輔助人类完成任務，降低成本、提升效率，成為人类可信賴的智能夥伴。

---

## 🚀 願景

讓 AI Agent 成為穩定、可控、可協作的通用智能助手，在專業領域做到精準可靠，在通用場景做到自然易用，持續進化但始終服務於人。

---

## ❓ 核心問題（起源）

成長計劃源於 **self-improving-agent** 的缺陷：

| 問題 | 說明 | 解決方式 |
|------|------|---------|
| ❌ **常態失憶** | 記不住用戶的糾正和偏好 | 記憶系統 + 自動記錄 |
| ❌ **有幻覺** | 編造信息 | 事實核查 + 記憶驗證 |
| ❌ **理解錯誤** | 誤解用戶意圖 | 溝通規範 + 確認機制 |
| ❌ **做事沒閉環** | 不記錄、不跟蹤、不反饋 | 自動化機制 + 心跳檢查 |
| ❌ **只說不做** | 只會嘴上保證但不幹實事 | 自動執行 + 推送通知 |
| ❌ **反覆犯錯** | 同類錯誤反覆出現 | 錯誤記錄 + 重複檢測 |
| ❌ **不長記性** | 用戶糾正後很快就忘 | 記憶復述 + 記憶巩固 |
| ❌ **文件亂記** | 7 個核心文件內容混亂 | 文件掃描 + 自動清理 |

## 💡 解決方案

### 1. 7 個核心文檔（AI 完整人格）

| 文檔 | 用途 | 核心問題 | 內容類型 |
|------|------|---------|---------|
| **SOUL.md** | 身份定義 | 「你是誰？」 | 價值觀、邊界、原則 |
| **IDENTITY.md** | 個人設定 | 「你的個性是什麼？」 | 名字、emoji、風格 |
| **USER.md** | 用戶信息 | 「你在幫助誰？」 | 用戶姓名、時區、偏好 |
| **AGENTS.md** | 行為規範 | 「你如何做？」 | 行為規則、工作流程 |
| **TOOLS.md** | 本地配置 | 「你用什麼工具？」 | 攝像頭、SSH、TTS 配置 |
| **MEMORY.md** | 長期記憶 | 「你記住了什麼？」 | 用戶偏好、關鍵教訓 |
| **HEARTBEAT.md** | 心跳配置 | 「你主動做什麼？」 | 心跳檢查清單 |

**文檔關係**：
```
SOUL.md（核心身份）
    ↓
IDENTITY.md（個性設定）
    ↓
USER.md（服務對象）
    ↓
AGENTS.md（行為方式）
    ↓
┌───────────────┐
│ TOOLS.md      │ ← 工具配置
│ MEMORY.md     │ ← 記憶經驗
│ HEARTBEAT.md  │ ← 主動行為
└───────────────┘
```

### 2. 記憶系統（四層架構）

```
實時捕獲 → HOT 層 → 記憶復述 → WARM 層 → 記憶巩固 → COLD 層 → 記憶清潔 → ARCHIVE 層

HOT 層（.learnings/）    ← 7 天內活躍記憶
    ↓ 記憶復述（每天 08:30）
WARM 層（memory/warm/）  ← 30 天內近期經驗
    ↓ 記憶巩固（每週一 05:00）
COLD 層（MEMORY.md）     ← 永久保存精選記憶
    ↓ 記憶清潔（每月 1 日 06:00）
ARCHIVE 層（.archive/）  ← 按需歸檔歷史記錄
```

**自動化腳本**：
- `auto-memory-hook.sh` - 實時記憶捕獲
- `memory-retell.sh` - 記憶復述（每天 08:30）
- `memory-consolidate.sh` - 記憶巩固（每週一 05:00）
- `memory-hygiene.sh` - 記憶清潔（每月 1 日 06:00）
- `memory-search.sh` - 記憶檢索優化（每週五 10:00）

### 4. 7 個核心文件掃描（v4.8.2 新增）

**腳本**: `scan-core-files.sh`  
**頻率**: 每週五 15:00 自動執行

**檢查內容**：
1. ✅ **內容規範性** - 檢查文件內容是否符合定義
2. ✅ **重複內容** - 檢查不同文件之間的重複內容
3. ✅ **優化建議** - 生成需要刪除/移除/遷移的建議
4. ✅ **飛書確認** - 推送確認消息給用戶

**檢測規則**：

| 文件 | 不應該包含 |
|------|-----------|
| **SOUL.md** | appId, appSecret, URL, 應該，禁止，規範 |
| **AGENTS.md** | appId, appSecret, 攝像頭，SSH, TTS |
| **TOOLS.md** | 應該，不應該，必須，禁止，規範，流程 |
| **MEMORY.md** | appId, appSecret, URL, 應該，禁止，規範 |
| **HEARTBEAT.md** | 流程圖（┌─ │ └─ → ↓） |

**常見重複檢測**：
- 時間詞彙、安全紅線、飛書配置、記憶系統、溝通規範、搜索工具

## 🚀 快速開始

### 了解成長計劃

1. **閱讀本文檔** - 了解成長計劃的使命、願景和架構
2. **查看架構文檔** - [docs/architecture/overview.md](docs/architecture/overview.md)
3. **閱讀版本歷史** - [docs/releases/](docs/releases/)

### 使用成長計劃

**作為用戶**：
- 糾正 AI 的錯誤 → 自動記錄到 `.learnings/LEARNINGS.md`
- 要求 AI 記住某事 → 自動記錄到 `MEMORY.md`
- 查看 AI 的改進 → 查看 [docs/releases/](docs/releases/)
- 確認文件優化 → 飛書推送確認消息

**作為開發者**：
- 添加新功能 → 更新 `AGENTS.md`
- 優化配置 → 更新 `TOOLS.md`
- 記錄經驗 → 更新 `.learnings/LEARNINGS.md`
- 查看掃描報告 → `memory/scan-report-YYYYMMDD.md`

### 版本管理

**查看當前版本**：
```bash
grep "version:" ~/.openclaw/workspace/skills/self-improving-agent-pro/SKILL.md
```

**同步版本號**：
```bash
~/.openclaw/workspace/.scripts/sync-version.sh [新版本號]
```

### 文件掃描

**手動執行掃描**：
```bash
~/.openclaw/workspace/.scripts/scan-core-files.sh
```

**查看掃描報告**：
```bash
cat ~/.openclaw/workspace/memory/scan-report-$(date +%Y%m%d).md
```
